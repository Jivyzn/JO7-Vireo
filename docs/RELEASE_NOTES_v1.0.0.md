# JØ7 VIREO v1.0.0 — public research release

This release packages the original JØ7 VIREO research prototype into a documented, configurable and testable open-source repository.

## Included

- Hailo/GStreamer object-detection callback
- compiled `yolov8m.hef` deployment model
- offline Vosk voice assistant
- optional Coqui TTS and Ollama integration
- eSpeak fallback when personal announcement WAVs are absent
- voice-controlled SG90 camera-servo script
- ESP32/VL53L0X directional haptic-belt firmware
- archived RP2040/ultrasonic belt prototype
- research report and selected project images
- hardware, installation, model, dataset, performance and safety documentation
- unit tests and GitHub Actions CI

## Important

VIREO remains a research prototype. It is not a certified medical device and is not a replacement for a white cane, guide dog, mobility training or human assistance. Prototype results in the report have not been independently reproduced by this repository release.
