# Code of conduct

This project welcomes respectful participation from disabled users, accessibility specialists, students, researchers, engineers and makers.

Be considerate, specific and constructive. Do not dismiss lived experience, pressure people to disclose medical information, publish private test data, or describe disability in demeaning terms. Technical criticism is welcome when it addresses the work rather than the person.

Project maintainers may edit or remove contributions that are abusive, unsafe, discriminatory, misleading or unrelated to the project's purpose.
